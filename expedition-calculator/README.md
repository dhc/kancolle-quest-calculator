# 艦これ 遠征収支シミュレータ v1.7（試作版）

艦これで普段実施している遠征の**資源獲得量（期待値）**を、週間・月間・年間で概算する非公式ツールです。通常は回数ベースの収支計算として使い、必要な場合だけ第2〜第4艦隊の開始時刻を管理するスケジューラーを利用できます。

## すぐ使う

`index.html`（単一HTMLファイル）をChrome、Edgeなどのブラウザで開いてください。インストール、サーバー、アカウントは不要です。GitHub Pagesなどの静的ホスティングにも配置できます。設定はそのブラウザの`localStorage`に保存します。別ブラウザ・別端末への移行には「JSON保存」「JSONインポート」を利用します。

**初期状態では遠征登録が空なので収入は0です。** 「運用プリセット」→「+ 遠征を追加」で入力するか、「サンプル運用を読み込む」で操作例を試せます。

## 画面と計算方法

### 運用プリセット

1. 名前自由のプリセットに、遠征名と**1日何回実施するか**を入力します。
2. 週間の基本運用で、例えば「プリセット1＝5日」「プリセット2＝2日」と割り当てます。
3. メンテなどの例外がある場合は別プリセットを作り、「月単位の例外」で月何日、どの通常プリセットの日を置き換えるか指定します。
4. 必要なら「月1回の遠征」にマンスリー遠征を登録します。これらは週間プリセットには含めず月・年間の見込みに加えます。

週間獲得量＝各プリセットの1日獲得期待量×週当たり日数の合計。月間は `365 / 7 / 12` 週に換算して、例外による置換差分と月次遠征を加えます。年間は月間を12倍します。**厳密な暦による集計ではなく、平均的な月・年の概算**です。

例外は加算ではなく置換なので、通常日の報酬と二重計上しません。置換元の週当たり日数を超える例外は警告します。

### 遠征時間・編成別の占有時間（v1.1）

- 61遠征に登録されている所要時間（分）を、遠征行に「1回の所要時間」「設定回数分の占有時間」として表示します。
- 各プリセットで **1日あたりの延べ占有時間＝Σ（遠征所要時間×実施回数）** を計算し、登録済み編成ごとに内訳表示します。
- 編成を指定していない遠征、および削除済み編成を参照する遠征は、独立した **「編成なし」** にまとめます。編成なしの占有時間も合計に含めます。
- **3艦隊×24時間＝72時間／日** を超えるプリセットは警告します。登録済みの各編成についても24時間／日を超えた場合に警告します。編成なしについては個別の24時間判定ができません。
- 週間・月間・年間の結果にも延べ占有時間を表示し、月間例外による置換やマンスリー遠征も月・年の延べ時間に反映します。
- **月次遠征はプリセットの1日72時間のチェックには含めません**。月次遠征自体の時間は別途集計します。
- これは必要条件の簡易検査であり、**遠征の開始・終了時刻や実際の同時運用はこの集計自体では検証しません**。別の「スケジューラー」画面では、第2〜第4艦隊の枠ごとに時間重複を確認できます。合計が72時間以下でも、実際に実行可能とは限りません。

### スケジューラー（v1.7・任意）

「スケジューラー」画面でプリセットを選び、**「このプリセットの予定を作成」**を押すと、プリセットに登録した「遠征 × 回数/日」を出発1回ごとの行に展開します。各行に次の3つの項目を設定します。

- **遠征名**：出発1回ごとに選択。1回だけ別の遠征へ変更しても、ほかの出発行は変更されません。
- **艦隊枠**：実際に遠征を出せる第2・第3・第4艦隊。艦隊編成プリセットとは別の概念です。
- **開始時刻**：コロンを省略した4桁数字の `HHMM`（24時間制、例 `0800`、`2330`）。終了時刻は遠征時間から計算します。`2400`や`2360`のような不正な時刻は登録しません。入力欄は4桁で表示し、帰投表示とタイムラインは`HH:MM`表記です。
- **使用編成**：任意。艦娘・装備・キラ・補給費の計算に使います。編成未設定でもスケジュールを組めます。

**1日の基準時刻（v1.5）**：スケジューラーのプリセットごとに `HHMM` 4桁で指定します。初期値は `0000` で、古いJSONには `dayStart` がなくても自動的に `0000` として扱います。例えば `0700` にすると、**当日07:00〜翌日07:00** を1つの運用日として扱います。翌日 `0100`、`0600` といった出発も同じ運用日です。帰投が翌07:00を超える場合も保存できますが、**基準時刻超過の警告**を表示します。同一艦隊枠の時間重複も入力を禁止せず、注意事項として表示します。基準時刻変更時にも既存予定を再検査して警告します。別プリセットへの切り替え日の干渉は引き続き対象外です。

タイムラインは基準時刻を左端、翌日の基準時刻を右端にして表示します。収支計算は登録済み遠征の回数で計算するため、基準時刻を変えるだけでは獲得量・補給費は変わりません。

**触れない時間帯（v1.6）**：プリセットごとに複数の時間帯を `HHMM`（4桁）の開始・終了で登録できます。例えば `0900〜1800`、`2300〜0700` です。開始が終了より遅い場合は翌日にまたがるものと解釈し、重複する時間帯はまとめて扱います。帰投がこの時間帯の内部に入る遠征を「遠征複製」すると、新しい遠征の開始時刻を**触れない時間帯が明けた時刻**に自動的に繰り下げます。終了時刻ちょうどは操作できる扱いです。元の遠征の時刻は変わりません。繰り下げにより翌日の基準時刻を越えたり、他の遠征と重複したりする場合も複製自体は可能で、警告を表示します。翌運用日に進む予定は時刻だけでなく運用日のずれも保持します。

手動設定した既存予定は勝手に移動しません。触れない時間帯内に手動で設定した出発は、画面で注意を表示します。時間帯はタイムラインに斜線で表示されます。既存のv1.5設定・JSONは時間帯なしとして継承されます。出発時刻と収支計算は従来どおりの仕組みを維持しています。

画面上のタイムラインは第2〜第4艦隊の占有時間を表示します。**同じ艦隊枠**で時間が重複する変更も登録でき、目立つ警告で確認できます。翌日の基準時刻までを24時間タイムラインに表示し、それ以降の予定は一覧に警告を表示します。また、**毎日そのプリセットを繰り返した場合の前日・翌日との重複**も確認します。終了直後の再出発は許可します。**異なる艦隊枠**で同じ編成を同時に使用する場合は警告します（禁止はしません）。編成が別でも同じ艦娘がいるケースはまだ検出しません。

各出発予定にある **「遠征複製」** は、元の遠征・艦隊枠・使用編成・大成功率・大発補正・補給設定を独立した1回分としてコピーし、**開始時刻を元の帰投時刻に自動設定**します。ただし、帰投時刻が登録済みの「触れない時間帯」に入る場合は、操作可能になる時刻まで繰り下げます。23時出発など帰投が翌日になる場合、翌日の時刻を日次サイクル上の4桁時刻として設定します。既存予定と重なる場合や、複製の出発が翌運用日になる場合も登録でき、警告表示になります。翌運用日に進んだ複製は「翌運用日 +1日」などと表示され、必要なら「基本日に戻す」で修正できます。元の予定は変更しません。元の開始時刻が未登録なら複製先も未設定になります。

「遠征を1回追加」「削除」と運用プリセットの回数は連動します。元の運用プリセットで回数を変更した場合も、時刻の割当は可能な範囲で維持し、不足分は未配置として追加します。プリセットを複製した場合には時刻・艦隊枠も複製されます。古いv1系設定は読み込めます。

**未配置の出発行も、獲得期待値や週間・月間・年間の収支計算には含まれます。** スケジュールを完成させなくても収支計算器の機能は変わりません。不要なら「予定の時刻設定を解除」で出発時刻と艦隊枠だけを削除できます。

**制限**：スケジューラーは「あるプリセットを1日単位で繰り返す」想定です。異なるプリセットに切り替わる前後の日の夜間・早朝の干渉は、曜日の厳密な並びを持たないため未検証です。月次遠征の開始時刻、艦隊の補給・帰投操作に要する時間、キラ維持や出現条件も未検証です。タイムライン自体は収支に補正をかけず、元の遠征回数・編成に対応した共通計算エンジンを使います。

### 遠征選択メニュー（v1.2）

「運用プリセット」「編成別遠征」の遠征選択欄では、各遠征候補に基本報酬で獲得できる資源を色付きの「燃」「弾」「鋼」「ボ」で表示し、その右端に所要時間を `H:MM` 形式（例：15分＝`0:15`、1時間30分＝`1:30`）で表示します。資源バッジにマウスを合わせると、その遠征の基本報酬量も確認できます。大発補正・大成功率・補給消費を差し引いた収支ではなく、**遠征マスターに登録した通常成功時の基本報酬**を示しています。

プルダウンは検索欄で遠征番号・遠征名による絞り込みが可能です。キーボードの上下矢印で候補移動、Enterで選択、Escで閉じられます。候補の選択は従来の保存形式に反映されるため、v1.1の設定を引き継ぎます。

### 編成別遠征（v1.1）

「編成別遠征」画面では、プリセットを選び、各登録済み編成または「編成なし」を起点に、その編成で回す遠征を追加・変更・削除できます。
「運用プリセット」と同一の遠征行を編集するため、変更結果は両方の画面に即座に反映されます。
画面下部には折りたたみ式の月次遠征編集欄があります。

### 大成功率と大発補正

- 初期の大成功率は**共通80%**です。これはユーザーが変更できる例示的初期値で、どの遠征でも自動的に80%になるという意味ではありません。
- 各遠征行の「補正・詳細」を開くと、個別の大成功率（0〜100%）や大発報酬補正を手動指定できます。
- 艦隊編成を指定すると、通常型の全キラ4/5/6隻や特定のドラム缶型に限り、編成から大成功率を推定します。**特殊判定型などは共通確率にフォールバックするため、必要なら個別指定してください**。
- 通常成功時と大成功時の報酬を個別に端数処理してから、確率による期待値を算出します。
- 大発系は対応装備に限り基本補正・特大発の別枠・改修補正・鬼怒改二の固有補正を概算します。装備ID未対応の特殊装備や例外ルールがある場合は手動指定を優先してください。
- **成功そのものの失敗率は0%**と仮定しています。大成功率と成功率は別です。

### 艦隊・装備（任意）

「艦隊・装備」で艦娘ごとのキラ、レベル、ケッコン、基礎燃料・弾薬消費量（ケッコン前の満タン補給量）、装備を入力できます。

各遠征行へ編成を指定すると、原則として自動で「編成から大成功率を推定」「装備から大発補正を計算」に切り替わります。遠征ごとの詳細設定で手動に変更もできます。編成から補給消費を算出するには**全艦の基礎燃料・弾薬消費量**が必要です。未登録でも**獲得量の計算は可能**です。

補給費をすべて計算できると「純収支」表示に切り替えられます。編成未登録でも遠征行の詳細から手動補給消費量を指定できます。未設定の補給消費を0とはみなさず、純収支は「未計算」とします。

### 制空権シミュレータの編成のインポート

「艦隊・装備」→「制空権シミュレータからインポート」で、制空権シミュレータv2などから取得できる**デッキビルダー形式JSON**を貼り付けます。`f1`～`f4` の編成、艦娘ID・レベル、装備ID・改修値を取り込みます。

**制限**：現時点では艦娘IDから艦名・基礎燃費を自動検索しません。艦名はID表示になり、基礎燃費とキラ状態は手動補完が必要です。共有URLの直接取得ではなく、JSONの貼り付け方式です。データはブラウザ内で処理し、外部送信しません。

### 条件A/B比較

「条件を一時保存」を押して現在のプリセット・艦隊編成・割当・補正設定をスナップショットとして記録します（最大8件）。保存済み条件と編集中の設定、または保存済み条件同士を比較できます。比較の差分は `B − A` です。

通常設定はブラウザ内に保存されますが、一時比較用スナップショットはそのタブのセッションストレージを利用しています。長期保存が必要な条件はJSONバックアップを利用してください。

## 収録データと制限

- 通常・月次の**61遠征**（そのうち月次16件）を初期データとして収録。支援艦隊の遠征は対象外です。
- 艦これの遠征報酬、消費率、大発・大成功のルールは複雑です。初期収録のデータ・補正式は試作段階であり、特に特殊遠征、複数ボーナスの端数、個別成功条件の再現について**ゲーム実測値と一致する保証はありません**。
- ランダム獲得アイテム（バケツや釘など）の報酬確率は未収録です。ネジは「大成功時に確定で付与される」とデータ上確認した一部の月次遠征のみ計上します。
- 遠征失敗率、艦隊レベル等の出撃条件の検証、キラ付けの消費、被害・修理費は対象外です。時刻を登録した場合に限りスケジューラー画面で同じ艦隊枠の時間重複を確認します。週間のプリセット切替日や月次遠征の日付跨ぎは対象外です。
- これらの制限があるため、結果は実際の収支ではなく**見込み（期待値・概算）**です。
- 個人制作の**非公式**ファンツールです。ゲーム運営・攻略Wikiとは無関係です。

## 開発・テスト

`index.html` は単体配布用に全データ・CSS・JSを埋め込んでいます。編集用のソースは以下のとおりです。

```text
index.template.html  ベースとなるHTML
style.css            スタイル
engine.js            計算ロジック
app.js               UI
expeditions.json     遠征マスター
build.py             単体HTML生成
engine_test.js       Node.jsユニットテスト
```

再ビルド（Python 3）:

```bash
python build.py
```

計算エンジンのテスト（Node.js）:

```bash
node engine_test.js
```

v1.6ではさらに操作不能時間帯・深夜をまたぐ時間帯・連続する時間帯・複製の自動繰り下げを確認しています。v1.7では時間重複・基準時刻超過を警告表示に変更し、翌運用日に入る複製の日付オフセットを保持する設計に変更しました。

開発時、Chromium + Playwrightで入力、月間例外、補給計算、条件比較、デッキビルダーJSONインポート、モバイル表示、編成別遠征の双方向編集、24/72時間警告に加え、スケジューラーの出発行展開、時間重複の警告、日をまたぐ処理、回数の連動、プリセット複製を確認しています。

### v1.7：スケジューラーの警告優先ポリシー

- 同一艦隊枠の重複・基準時刻越え・別艦隊枠での編成重複は入力を禁止せず、注意として表示します。警告付きでも遠征回数と収支に計上されます。
- 遠征複製が運用日の境界を超えた場合も複製します。翌運用日の開始と誤って前日の開始を混同しないため、`dayOffset` を保持し、翌運用日と明示します。タイムラインはあくまで基準時刻から24時間を表示します。
- 時刻の不正値（`2460` など）や、触れない時間帯の開始・終了が同一になる入力は計算不能のため従来どおり受け付けません。
- 登録可能であることはゲーム内で実行可能であることを保証しません。
